# Project Notes

This is a static website. `index.html` is the current working app. The interface should remain in English. User notes are stored in browser `localStorage` and are not part of this repository.

`cloud-sync.js` and `supabase-schema.sql` are inactive drafts. Cloud sync has not been wired into the app. Do not activate an upload of existing notes without the user's explicit approval for the data and destination.

Work on your own Git branch. Keep changes focused, verify the site in a browser when possible, and commit your work. Do not put passwords, secret keys, or exported note backups in Git.
